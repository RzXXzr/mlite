Cek Sinkronisasi PCare vs mLITE

Fitur ini membandingkan data pendaftaran di server PCare BPJS dengan data bridging di mLITE. Berguna untuk mendeteksi pendaftaran yang ada di PCare tapi tidak tercatat di mLITE (misal: duplikat/manual), atau sebaliknya.


Pilih tanggal dan klik "Cek Sinkronisasi" untuk memulai pengecekan.
